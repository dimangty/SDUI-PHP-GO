# iOS: сверка с приложенным эскизом — 2026-10-27

**Результат: визуальное соответствие НЕ подтверждено. Есть существенные
расхождения дизайн-системы и компоновки. Функциональный smoke PASS не означает
совпадение интерфейса с эскизом.**

## Что проверено

Реальная установленная Debug-сборка `com.shopkmp.ios` на локальном iPhone 17 Pro,
iOS 26.2, Xcode 26.2. Backend — disposable edge `http://127.0.0.1:58196`.
Исходный мобильный код не изменялся. Сборка выполнена с override backend URL;
значение проверено в собранном Info.plist. Созданы только синтетические аккаунты
через UI; реальные пользователи и денежные операции не затрагивались.

Основа сравнения — картинка пользователя с десятью экранами. В репозитории
также есть соответствующий эскиз `docs/images/frontend-sketch.svg`/`.png`;
палитра SVG содержит `#0f766e`, `#fffdf8`, `#f1efe8`, `#d9efec`.
Это качественная сверка композиции и стилей, а не выдуманный процент pixel-match:
макет концептуальный, viewport/данные отличаются.

## Общие расхождения

1. **Цвета.** Эскиз использует бирюзовый `#0F766E`, тёплый светлый фон и бежевые
   поля. Приложение — фиолетовый `#6200EE`, белые/холодные светло-серые поверхности,
   сиреневую нижнюю панель, синие аватары и PIN-индикаторы.
2. **Шапки.** Вместо бирюзовых AppBar со стрелкой/иконками отображаются обычные
   заголовки в контенте и текстовые «Назад»/«Обновить». На регистрации — `Back`.
3. **Навигация.** Названия четырёх вкладок совпадают, но иконки отсутствуют:
   `NavigationBarItem(icon = {})`. Цвета/фон и active indicator отличаются.
4. **Поля и кнопки.** Используются стандартные Material3 OutlinedTextField и
   pill-кнопки. В эскизе — компактные заполненные скруглённые поля и бирюзовые
   прямоугольные CTA. Disabled-цвет сам по себе не считался дефектом: сравнение
   учитывает состояние формы; цвет enabled CTA виден на товаре/корзине/профиле.

| 10 | Редактирование | Поля имени/телефона/email/адреса и save есть; email readonly. Нет бирюзовой шапки/lock-иконки email; заголовок переносится на две строки. Дополнительный подтверждённый дефект персонализации: PIN Login приветствует
«Иван, с возвращением!» даже для другого тестового имени. Это не требование
подставлять имя из демонстрационного макета: строка hardcoded в `PinScreen.kt:54`.
