# Actual installed after-reference evidence

These contact sheets are composed only from the ten explicitly named actual app
PNG exports, in reference order. Each screenshot retains its aspect ratio; no UI
content is drawn, replaced or fabricated. Outside-image captions identify states.

- `ios-after-contact-sheet.png`
- `android-after-contact-sheet.png`
- `installed-images.json`: exact receipt IDs, dimensions and SHA-256 checksums
  for all 13 exports per platform and both derived contact sheets.

Inputs are the recorded fresh exports under `docs/evidence/ios/` and
`docs/evidence/android/`: empty Login/Registration, partial Create PIN (two dots),
partial PIN Login (three dots), Home, Product, Cart/checkout, paid Orders, Profile
and native Edit Profile. Supplemental images are Profile actions, native checkout
confirmation and order detail. Browser/provider/capability, credential and raw
hierarchy captures are excluded. Profile/editor data belongs only to the
UI-created synthetic accounts; their public identifiers cannot derive passwords.

See [`INSTALLED_VISUAL_REPORT.md`](../INSTALLED_VISUAL_REPORT.md) for actual test
commands/results, per-state boundaries, privacy checks and remaining limitations.
Images are evidence of actual installed states, not certification of pixel-perfect
reference conformance or unsupported photo/notifications functionality.
