# Installed iOS ten-screen evidence

Generated by `scripts/run_ios_installed_journey.py` on local iPhone 17 Pro /
iOS 26.2. App and independent verifier share the configured disposable root,
currently `http://127.0.0.1:58196`. Raw XCTest output/results remain private and
temporary; only fixed safe diagnostics and this explicit app-image set export.

## Privacy and capabilities

- Only synthetic account name/email/phone/address appear in Profile/editor.
  The public email identifier and the random password use independent randomness;
  an exported profile identifier cannot derive the credential.
- No plaintext password, PIN digit sequence, token, provider browser/capability
  URI, Safari screenshot or raw hierarchy is exported. PIN filenames encode only
  the entered **count**, and pictures show masked dots/public keypad keys.
- Login/Registration snapshots are guarded by empty-input assertions. All
  captures require the actual app foreground and a finite allowed filename.
- Biometric presentation is the actual native state, never toggled for a photo.
  Photo change is honestly disabled with its capability caption; notifications
  remain unsupported. The editor is exited through Back without saving, and
  profile/default-address identity is checked unchanged.
- Each run updates only declared latest evidence and also keeps a distinct safe
  receipt/images in a mode-0700 directory under the preapproved temporary root.
  Historical failed-run entries in `docs/MOBILE_E2E_REPORT.md` remain intact.

The existing simulator helper resets only nonsecret `backend_device_id`; tokens
and other Keychain entries are preserved. Prior sessions recover through UI.
The observer performs its own real password login (refreshed before commerce),
never injects tokens into the app, and only reads business state. Signup, PIN,
cart, checkout and demo payment occur through actual app/Safari UI.
