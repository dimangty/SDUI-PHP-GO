# Installed iOS CARD journey evidence

Generated by `python3 scripts/run_ios_installed_journey.py` on the booted
iPhone17Pro/iOS26.2 simulator, using the real shared edge at127.0.0.1:58095.

- `xctest-summary.txt`: actual result, fixed nonsecret milestone logs, native
  element-type/selection observations, canonical order/product IDs and amount.
- `product.png`: selected persisted lamp and exact public price.
- `checkout-confirmation.png`: local native confirmation before order creation.
- `orders-paid.png`: the specific paid order, not merely a status filter.
- `order-detail.png`: purchased lamp, quantity, snapshot price, address and CARD.

Screenshots contain only nonsecret app content. There are no browser/capability,
credentials, profile or PIN captures. Raw XCTest output/activities, generated
credentials and xcresult attachments are withheld and deleted from the helper's
private temporary directory. Only these four explicitly named app attachments
are exported. Each run replaces only this helper's declared evidence and app.

For fresh-account repeatability, the simulator-only native helper deletes just
the nonsecret `shopkmp/backend_device_id` Keychain setting before install. All
tokens and other Keychain entries are preserved; any prior session is recovered
by installed UI logout. The app generates its normal new installation UUID.
This avoids globally unique PIN-device collisions without simulator reset,
token injection, backend cleanup or changes to production identity generation.

The independent URLSession verifier uses a real password login for this run's
UI-created account. Business state verification is GET-only. Signup, PIN, cart,
address, checkout and payment mutations occur through the installed UI/Safari.
